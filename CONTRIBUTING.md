# Contributing

Bug reports and focused pull requests are welcome. Use GitHub issues for bugs and feature discussions; report security vulnerabilities privately as described in [SECURITY.md](SECURITY.md).

## Local Setup

Follow [README.md](README.md) to create a virtual environment, then install development dependencies:

```sh
python -m pip install -r requirements-dev.txt
python -m pytest tests -q
```

Run these commands with the virtual environment's Python. Use a separate database for development, especially when testing migrations or MCP tools. Never include personal board data in tests or reports.

## Pull Requests

- Explain the problem, the behavior change, and how you verified it.
- Keep changes focused and follow the surrounding Python, JavaScript, and CSS conventions.
- Add regression coverage for changed API, migration, or MCP behavior in the existing test suite.
- Keep dependencies in the appropriate file: web runtime, optional MCP runtime, or development tools.
- Document changes to configuration, API contracts, and database migrations.
- Test browser-facing changes on narrow and wide viewports and note any remaining limitations.
- Preserve existing SQLite data on upgrade and maintain stale-write checks and follow-up audit trails.
- Do not commit databases, virtual environments, generated bytecode, local client configuration, or secrets.

CI must pass before merge. Be respectful and constructive in issues and reviews. By contributing, you agree to license your contribution under this project's MIT license.
